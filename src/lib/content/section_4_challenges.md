# SEÇÃO 4: DESAFIOS

Desafios sobre polígonos:

1. **Polígonos Dinâmicos**: Você consegue criar uma função que gera polígonos regulares aleatórios com N lados e testa colisões entre eles?
2. **Otimização com Bounding Box**: Como você viu, o teste [Polígono/Polígono](poly-poly) é computacionalmente pesado. Você consegue aplicar uma verificação preliminar usando o círculo delimitador ([Círculo/Círculo](circle-circle)) ou caixa delimitadora ([Retângulo/Retângulo](rect-rect)) antes de executar a checagem detalhada?
